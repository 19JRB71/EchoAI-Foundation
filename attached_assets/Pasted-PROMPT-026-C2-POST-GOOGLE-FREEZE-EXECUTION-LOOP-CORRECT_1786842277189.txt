J. 409 CORRECTIVE DESIGN
============================================================

Design bounded:

409 -> reconcile -> poll authoritative session state -> resume if appropriate.

Requirements:

1. 409 itself is not treated as fatal.

2. Reconciliation reads authoritative session state.

3. Completed steps are immediately reflected.

4. If another execution is genuinely active, poll with bounded backoff.

5. If that execution completes, continue from the next correct step.

6. If owner action is required, stop in awaiting-owner-action.

7. If the authoritative state records a failure, render the visible failure.

8. If bounded attempts expire without convergence, render an honest actionable error.

9. Never spin forever.

10. Never start duplicate work merely because a collision occurred.

11. Never duplicate side effects.
