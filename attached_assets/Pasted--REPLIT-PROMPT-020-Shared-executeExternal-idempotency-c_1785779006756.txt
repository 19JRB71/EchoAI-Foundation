# REPLIT_PROMPT_020 — Shared executeExternal(): idempotency, classified retry, action ledger, failure queue, alerts
**Phase E · Prereqs: 010, 009**

**Objective:** One helper wrapping every external side-effect call: (a) idempotency key per action (dedup guaranteed at the DB level); (b) retry ONLY on explicitly classified transient errors (extract the publish path's proven policy); (c) external_actions ledger row per ATTEMPT (action, brand, task_id, key, request summary, response/provider ids, outcome); (d) terminal failures land in a failure queue (MANUAL_REVIEW tasks) with owner-visible alerting (email + web push using the proven channels).
**Reason:** Audit docs 09/10: retry/idempotency reinvented per feature; silent-failure classes; no attempt-level audit. Lesson files define the correct patterns — standardize them.
**Scope:** utils/executeExternal.js + migration + adoption by the three spine flows (publish, ad launch, email) — other callers adopt in later phases, listed not migrated. **Out of scope:** changing any retry POLICY beyond extraction; new notification channels; global list.
**Preflight:** inventory current per-feature retry/idempotency implementations and the transient-error classifier locations.
**Implementation:** helper is the only path for the three flows (grep-verify); alert fires on terminal failure with plain-language owner copy; ledger row before AND after provider call (attempt/outcome).
**Migration:** additive external_actions (+ unique index on idempotency key).
**Tenant isolation:** ledger rows brand-scoped. **Security:** ledger = audit trail; no secrets in request summaries.
**Honest state:** outcome recorded only from provider responses.
**External proof:** staged duplicate-fire test (same key twice ⇒ one provider call, proven by mock capture + ledger); one forced terminal failure ⇒ alert received (screenshot).
**Testing:** dedup, retry-classification, ledger, alert tests; suite green.
**Completion evidence:** inventory, diff, migration, tests, alert screenshot, commit, rollback.
**Definition of Done / End-of-Prompt Report / Stop Conditions:** GLOBAL_PROMPT_RULES.md applies in full. COMPLETE only if every criterion passed; undemonstrated = UNVERIFIED.
**Acceptance criteria:** three flows exclusively via helper (grep proof); dedup + alert demonstrated; suite green.
