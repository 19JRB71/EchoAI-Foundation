# REPLIT_PROMPT_009 (v2) — Task spine: schema + unified lifecycle + first adopter (social publish)
**Phase D · Prereqs: 006**

**Objective:** Create agent_tasks + agent_task_events and utils/taskSpine.js implementing the PLATFORM lifecycle (D-13): DRAFTED → REVIEWED → APPROVED → QUEUED → EXECUTING → PROVIDER_ACCEPTED → EXTERNALLY_VERIFIED → REPORTED → COMPLETED; failure/cancel states AUTH_REQUIRED, PERMISSION_DENIED, RATE_LIMITED, VALIDATION_FAILED, EXTERNAL_FAILURE, RETRY_SCHEDULED, MANUAL_REVIEW, CANCELLED. Adopt for exactly ONE flow end-to-end: scheduled social publish (Nova). external_post_id = PROVIDER_ACCEPTED evidence; Graph read-back (where available) = EXTERNALLY_VERIFIED; inclusion in owner-visible activity/report = REPORTED; COMPLETED closes it.
**Reason:** Audit doc 08: approval/execution semantics differ per feature; nothing records ownership; completion unverifiable. One spine, no agent framework. collaborationBus chokepoint + 122_collaboration_bus.sql exist dark; atomic-claim lesson pattern reusable.
**Scope:** the two tables, taskSpine.js (create/transition/attachEvidence, illegal transitions throw, every transition writes an event row: actor/from/to/at/meta), socialController adoption, one read-only owner "Approvals & Activity" list. **Out of scope:** other features (018/019); COLLAB flags; autonomy changes; global list.
**Preflight:** map today's publish flow states (scheduled_posts statuses) to the lifecycle; report the claim pattern reuse.
**Implementation:** owner scheduling a post = APPROVED (record actor); sweep claims atomically → EXECUTING; success → PROVIDER_ACCEPTED with post id → read-back → EXTERNALLY_VERIFIED → surfaces in activity → REPORTED → COMPLETED; classified failures map to failure states; retries unchanged, recorded as RETRY_SCHEDULED.
**Migration:** additive tables only. **Tenant isolation:** tasks brand-scoped; owner-only approval transitions; isolation test.
**Security:** event rows are the audit trail. **Honest state:** UI activity derives ONLY from task states.
**External proof:** one staging publish's full event trail ending EXTERNALLY_VERIFIED (screenshot + rows).
**Testing:** transition-legality tests; full-flow integration (mocked HTTP) asserting the trail; duplicate-claim test; suite green.
**Completion evidence:** schema, diff, tests, staging trail, commit, rollback.
**Definition of Done / End-of-Prompt Report / Stop Conditions:** GLOBAL_PROMPT_RULES.md applies in full. COMPLETE only if every criterion passed; undemonstrated = UNVERIFIED.
**Acceptance criteria:** full trail on a staging publish; no other feature behavior changed; suite green.
