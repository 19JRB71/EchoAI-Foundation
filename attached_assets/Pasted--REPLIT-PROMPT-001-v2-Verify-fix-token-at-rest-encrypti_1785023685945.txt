**Migration:** token backfill, reversible with ENCRYPTION_KEY. **Tenant isolation:** per global rules; tokens remain scoped as today. **Security:** ENCRYPTION_KEY required at boot in prod when integrations enabled — fail loudly if absent.

**External proof:** staging SQL `SELECT LEFT(access_token,10) ...` screenshot showing ciphertext, not `EAAB...`/`ya29...`; forged-webhook 400 test output.
**Testing:** encrypt round-trip unit test; forged-signature rejected; legitimate test event accepted; full suite green.
**Completion evidence:** preflight findings, diff, migration, test output, staging SQL screenshot, commit, rollback.
