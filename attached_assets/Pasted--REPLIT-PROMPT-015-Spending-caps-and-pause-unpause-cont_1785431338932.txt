# REPLIT_PROMPT_015 — Spending caps and pause/unpause controls (no-cap-no-unpause)
**Phase B · Prereqs: 005**

**Objective:** In-product pause/unpause for the FB chain, gated so UNPAUSE is impossible without (a) a per-brand daily spend cap set, (b) a platform-level cap, (c) an explicit recorded approval (who/when). Default pilot cap $5/day (D-6).
**Reason:** Today unpausing is a manual Facebook-side act with no cap; a spend bug is trust-ending. Completes Phase B's "pause and unpause controls, spending caps".
**Scope:** new ad_spend_caps (brand_id, daily_cap_cents, platform default row), unpause/pause endpoints calling Graph status updates on campaign+ad set+ad, approval recording, UI controls. **Out of scope:** budget optimization; auto-unpause; any automation deciding to spend; global list.
**Preflight:** confirm Graph status-update pattern already used (campaignController.js:340–344 daily_budget updates) and reuse its wrapper.
**Implementation:** deny unpause with clear copy when cap unset or requested budget exceeds cap; unpause = Graph updates to ACTIVE on all three objects + read-back (via 005 helper) before showing live; pause = symmetric; every transition writes an approval/audit row (actor, timestamp, cap at time).
**Migration:** additive caps table. **Tenant isolation:** caps and controls strictly brand-scoped; isolation test.
**Security:** approval rows are the audit trail; owner-only (requireOwner) on unpause.
**Honest state:** live only after read-back (inherits 005).
**External proof:** staging: attempt unpause without cap ⇒ denied (screenshot); DO NOT actually unpause to spend in this prompt — live spend happens first in Phase H on own businesses (D-7).
**Testing:** cap-enforcement tests (unset, exceeded, ok); approval-row tests; pause/unpause mocked-graph tests; suite green.
**Completion evidence:** diff, migration, tests, denial screenshot, commit, rollback.
**Definition of Done / End-of-Prompt Report / Stop Conditions:** GLOBAL_PROMPT_RULES.md applies in full. COMPLETE only if every criterion passed; undemonstrated = UNVERIFIED.
